# 실시간 시세 목록 성능 실험 (Flutter)

2,000개 종목이 초당 최대 15,000건 갱신되는 관심종목 목록을 Flutter로 만들면서, **설계 판단을 문서로 남기고 성능을 수치로 측정해 개선한 기록**입니다.

- 지연·역순 tick, 거래정지, 일시적 스트림 에러가 섞인 시세 피드에서 정합성을 지키는 구조
- 60fps와 신선도(화면 가격이 최신 tick 뒤 200ms 안에 반영)를 함께 지키는 갱신 방식
- 가장 순진한 구현(baseline)과 같은 조건에서 비교한 before/after 수치

> 이 저장소에는 문서와 측정 원본 수치만 담았습니다. 앱 소스 코드는 포함하지 않았습니다.

## 주요 결과 (요약)

- 화면 구성(build) 평균 시간: baseline 대비 시나리오별 약 30~47% 감소
- 배치 하나 처리(증분 집계 + 순위 유지): 전체 재계산 대비 약 11배 빠름
- 초성 검색: baseline 방식 대비 약 17배 빠름
- 화면 가격 반영 지연: 평균 약 12~14ms, 최악 약 28ms (빠른 스크롤 중 포함)

자세한 조건과 수치는 [PERF.md](PERF.md)에 있습니다.

## 측정 환경

- Galaxy S24+ (60Hz), Flutter profile 모드
- 같은 난수 seed로 만든 시세 배치를 baseline과 개선본에 똑같이 넣어 비교
- `integration_test` + `watchPerformance`로 모든 프레임 시간 수집
